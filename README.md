# 产品经理 SOP 模板包

从 PRD 到复盘：六套拿来即用的实战模板。所有【方括号】填空即可使用，覆盖一个需求从出生到结束的完整链路。

## 包含六套模板

| # | 模板 | 解决什么问题 |
|---|------|------------|
| 01 | PRD（产品需求文档）模板 | 让研发和测试不用猜：规则表、异常流清单、Given-When-Then 验收标准、灰度与回滚计划 |
| 02 | 竞品分析模板 | 先定目的再分析，强制输出 3 条行动建议，拒绝截图几十张结论零条 |
| 03 | 需求评审会 SOP | 45 分钟带着结论散会：会前 24h 清单、决策记录表、4 条红牌打回规则 |
| 04 | 上线 Checklist | 20 项检查分 5 组，任何一项不通过就不上 |
| 05 | 版本复盘模板 | 目标 vs 实际、5Why 归因、行动项不超过 3 条 |
| 06 | 用户访谈提纲 | 问过去的行为不问未来的意愿，原话与解读分离记录 |
